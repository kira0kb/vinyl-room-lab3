# Vinyl Room — лабораторная работа №3

Коллекция музыкальных альбомов на Laravel 12. За основу взяты пять альбомов, изображения и оформление из лабораторной №2. Теперь альбомы хранятся в SQLite: их можно просматривать, добавлять, изменять и удалять.

## Запуск на Mac

1. Распакуй архив и открой папку `vinyl_room_laravel_lab3` в VS Code через **File → Open Folder**.
2. Открой **Terminal → New Terminal**. Введи `pwd`: в конце пути должно быть `vinyl_room_laravel_lab3`. В этой папке находятся `artisan`, `composer.json` и `setup.sh`.
3. Один раз выполни:

```bash
bash setup.sh
```

4. После сообщения «Готово» запусти:

```bash
bash start.sh
```

5. Открой в браузере **http://127.0.0.1:8000**. Терминал оставь открытым. Для остановки нажми **Control+C**. В следующий раз достаточно `bash start.sh`.

Первый запуск требует интернета: устанавливаются зависимости. Папки `vendor` и `node_modules` отсутствуют в архиве по требованию преподавателя. После установки обычный запуск приложения не требует интернета; внешняя ссылка на Яндекс Музыку требует подключения.

Это серверное приложение. Двойным щелчком по `index.php` оно не запускается.

### Если нужные программы ещё не установлены

Проверь в терминале:

```bash
php -v
composer --version
node -v
npm -v
git --version
```

Нужны PHP 8.3 или новее, Composer 2, Node.js от 20.19 и Git. У PHP должны быть включены `gd`, `pdo_sqlite`, `mbstring`, `fileinfo`, `dom` и `xml`. `setup.sh` проверяет их перед установкой.

Если уже установлен Homebrew, зависимости можно установить так:

```bash
brew install php composer node git
```

Если команда `brew` не найдена, сначала установи Homebrew по инструкции с https://brew.sh/ и выполни предложенные установщиком команды для PATH. Затем заново открой терминал VS Code. Если установлен другой PHP, ориентируйся на вывод `which php` и `php -v`.

Приложение проверено на PHP 8.3.6 и Node.js 24.22.1 в Linux. Скрипты запуска используют команды, доступные в Bash на macOS; запуск непосредственно на твоём Mac потребуется выполнить после скачивания.

## Что делает установка

`setup.sh` устанавливает пакеты из `composer.lock` и `package-lock.json`, копирует `.env.example` в `.env`, создаёт ключ приложения, пустой файл SQLite и таблицы через миграции. Затем сидер добавляет пять исходных альбомов, `storage:link` открывает доступ к обложкам, а Laravel Mix собирает JS и CSS.

Повторная установка сохраняет ключ и введённые записи. Сидер не дублирует альбомы и не возвращает удалённые. **Не используй `migrate:fresh` для обычного запуска: эта команда удаляет таблицы и данные.**

В архиве есть исходные обложки и JSON для начального заполнения. Рабочая база создаётся при установке, чтобы создание таблицы через миграцию можно было показать преподавателю.

## Что реализовано

| Требование | Где смотреть |
| --- | --- |
| Laravel 12 и MVC | `app/Models`, `app/Http/Controllers`, `resources/views` |
| Пять объектов из ЛР №2 | `database/data/albums.json` и `AlbumSeeder` |
| SQLite, миграция и имена snake_case | `database/migrations/2026_10_31_000001_create_albums_table.php` |
| Eloquent, мутаторы и преобразование даты | `app/Models/Album.php` |
| Семь действий контроллера и ресурсные маршруты | `AlbumController.php`, `routes/web.php` |
| Отдельная подробная страница | `resources/views/albums/show.blade.php` |
| Общая форма создания и редактирования | `resources/views/albums/partials/form.blade.php` |
| HTML5, Bootstrap и серверная валидация | Форма, `resources/js/app.js`, `validatedData()` в контроллере |
| Загрузка и обработка обложек | `app/Services/CoverImage.php` |
| Хранение изображений в storage | `storage/app/public/albums` |
| Мягкое удаление | `SoftDeletes` в модели, `deleted_at` в таблице |
| Bootstrap, jQuery, SCSS и Laravel Mix | `package.json`, `webpack.mix.js`, `resources` |
| Готовые JS и CSS в public | `public/js/app.js`, `public/css/app.css` |
| Автоматическая сборка и обновление страницы | `npm run watch`, BrowserSync |
| Git и несколько коммитов | История в `.git`; команды для push/pull — `docs/GIT.md` |

Из прошлой работы сохранены цвета, карточки, обложки, описания, избранные композиции и адаптивная сетка. Подробности из Modal перенесены на отдельную страницу согласно ЛР №3. Стрелки клавиатуры переключают соседние страницы альбомов. Кнопку-заглушку «Загрузить» заменили действия управления коллекцией.

## Сборка и автоматическое обновление

Обычная сборка:

```bash
npm run build
```

Для работы над вёрсткой оставь сервер запущенным в первом терминале, открой **второй терминал в той же папке** и выполни:

```bash
npm run watch
```

При этом открывай **http://127.0.0.1:3000**. SCSS и JS пересобираются, а при изменении Blade страница обновляется. Порт 8000 — само приложение, порт 3000 — приложение с автоматическим обновлением. Если система не замечает изменения файлов, используй `npm run watch-poll`.

Webpack и часть зависимостей закреплены совместимыми с Laravel Mix версиями. При повторной установке используй `npm ci`, чтобы сохранить проверенные версии.

## Проверка и защита

```bash
php artisan test
php artisan route:list --path=albums
php artisan migrate:status
```

Тесты работают с отдельной SQLite-базой в памяти и не меняют твою коллекцию. Инструкции по Tinker, демонстрации CRUD и краткие объяснения кода находятся в `docs/DEFENSE.md`. Результаты проверки готового проекта — в `docs/CHECKS.md`.

Для сдачи также выполни действия из **`docs/GIT.md`**. История подготовки уже включена в архив, но личный удалённый репозиторий не подключён. Отправка в него (`push`) и получение изменений (`pull`) пока не выполнены.

## Если что-то не открылось

- `vendor/autoload.php` не найден: выполни `composer install` или полностью `bash setup.sh`.
- Не видны обложки: выполни `php artisan storage:link --force`.
- Ошибка `could not find driver`: в PHP отсутствует `pdo_sqlite`.
- Ошибка об отсутствии GD: установи/включи расширение `gd` у того PHP, который показывает `which php`.
- Ошибка 419: обнови страницу с формой и отправь её заново; не смешивай `localhost` и `127.0.0.1` в разных вкладках.
- Порт 8000 занят: останови прежний сервер через Control+C. Для другого порта запусти `php artisan serve --port=8001`; для watch тогда измени `proxy` в `webpack.mix.js`.
- Терминал сообщает `No such file or directory` для `setup.sh`: открой терминал именно в папке проекта, где находится этот файл.
