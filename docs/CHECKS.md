# Проверка проекта

Проверка завершена 1 ноября 2026 года. Среда проверки: Linux, PHP 8.3.6, Node.js 24.22.1, Laravel 12.70.2, Laravel Mix 6.0.49. Для проверки интерфейса использован Chromium. На компьютере пользователя запуск ещё не выполнялся.

## Проверки кода и установки

| Проверка | Результат |
| --- | --- |
| Установка из чистой копии без `.env`, базы, vendor и node_modules через `bash setup.sh` | Успешно |
| Создание SQLite, миграция и начальные данные | Созданы таблица и пять альбомов |
| `composer validate --strict` | Успешно |
| `npm ci` и `npm run build` | Успешно |
| `php artisan route:list --path=albums` | Семь ресурсных маршрутов |
| `php artisan test --compact` | 15 тестов, 67 проверок — успешно |
| Создание объекта через `php artisan tinker --execute` | Успешно, дата и название преобразованы |
| `npm run watch` | В браузере проверены обновление Blade и пересборка SCSS |
| Синтаксис скриптов Bash | Успешно |

Тест Tinker создавал объект внутри транзакции с последующим откатом. Это проверило сохранение без добавления лишнего демонстрационного альбома. Команды для самостоятельной демонстрации Tinker приведены в `DEFENSE.md`.

## Проверки в браузере

- Список выводит пять альбомов; все исходные обложки загружаются.
- Подробная страница открывается, стрелка клавиатуры переключает альбом.
- Пустая форма не отправляется; ограничения HTML5 работают.
- Создание с загрузкой обложки и заполненным треком проходит успешно.
- Редактирование без повторной загрузки сохраняет прежнюю обложку.
- Отменённое подтверждение удаления сохраняет карточку.
- Подтверждённое удаление убирает карточку; подробная страница удалённого объекта возвращает 404.
- Запрос без CSRF-токена возвращает 419.
- При ширине 390 px нет горизонтальной прокрутки, меню раскрывается, форма помещается в экран.
- Ошибок JavaScript в проверенных сценариях нет.
- Внешний вид списка, подробностей и формы проверен при ширине 1600 px; список и форма также проверены при ширине 390 px.

Автоматические тесты дополнительно проверяют серверную валидацию дат и файлов, размер результата 900 × 900, замену прежней загруженной обложки, обработку пустых композиций, Soft Deletes, повторный запуск сидера, мутаторы и экранирование пользовательского HTML.

## Что ещё нужно перед сдачей

Распаковать проект на своём компьютере, выполнить установку и открыть приложение. Подключить личный удалённый Git-репозиторий и выполнить `push` и `pull` по `GIT.md`. Эти действия с учётной записью пользователя здесь не выполнялись.
